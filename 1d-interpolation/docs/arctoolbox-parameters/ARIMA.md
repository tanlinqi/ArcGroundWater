# ARIMA ArcToolbox Parameters

| 顺序 | 参数 | 中文数据类型 | 要求 | 默认值 |
|---:|---|---|---|---|
| 0 | 输入时序文件 | 文件（多值） | 必选，CSV/Excel，多文件用分号分隔 | 无 |
| 1 | 时间字段 | 字符串 | 必选，验证器读取输入文件字段并生成下拉框 | 输入文件首字段 |
| 2 | 数值字段 | 字符串 | 必选，验证器读取输入文件字段并生成下拉框 | 输入文件第二字段 |
| 3 | 缺失值标记 | 双精度/字符串 | 可选，用于识别缺失值；不是下拉框 | -99999 |
| 4 | 按时间排序 | 布尔值 | 可选，复选框 | true |
| 5 | 重复时间处理 | 字符串 | 可选，下拉：error/mean/first/last | error |
| 6 | 输出 HTML 报告 | 文件 | 可选，验证器根据输入文件自动填充 | 自动生成 |
| 7 | 输出文件夹 | 文件夹 | 必选，验证器根据输入文件自动填充 | 输入文件所在文件夹 |
| 8 | 打开 HTML 报告 | 布尔值 | 可选，复选框 | true |
| 9 | 训练测试比例 | 字符串 | 可选，例如 8:2 或 0.2；不是下拉框 | 8:2 |
| 10 | 插补最小值 | 双精度 | 可选，插补结果下限；不是下拉框 | 0 |
| 11 | 插补最大值 | 双精度 | 可选，插补结果上限；留空表示不限制 | 空 |
| 12 | p 阶数 | 长整型 | 可选，AR 阶数；单值；不是下拉框 | 1 |
| 13 | d 差分阶数 | 长整型 | 可选，差分阶数；单值；不是下拉框 | 0 |
| 14 | q 阶数 | 长整型 | 可选，MA 阶数；单值；不是下拉框 | 1 |
| 15 | 启用季节项 | 布尔值 | 可选，复选框 | false |
| 16 | 季节 P 阶数 | 长整型 | 可选，季节 AR 阶数；单值；不是下拉框 | 0 |
| 17 | 季节 D 阶数 | 长整型 | 可选，季节差分阶数；单值；不是下拉框 | 0 |
| 18 | 季节 Q 阶数 | 长整型 | 可选，季节 MA 阶数；单值；不是下拉框 | 0 |
| 19 | 季节周期 | 长整型 | 可选，月尺度通常为 12；不是下拉框 | 12 |
| 20 | 趋势项 | 字符串 | 可选，下拉：n/c/t/ct | n |
| 21 | 信息准则 | 字符串 | 可选，下拉：aic/bic | aic |
| 22 | 强制平稳 | 布尔值 | 可选，复选框 | true |
| 23 | 强制可逆 | 布尔值 | 可选，复选框 | true |
| 24 | Python3 路径 | 文件 | 可选，python.exe；留空使用默认环境或 ARCWATER_PY3 | 空 |
