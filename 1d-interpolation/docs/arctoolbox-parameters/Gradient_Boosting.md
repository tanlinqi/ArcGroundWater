# Gradient Boosting ArcToolbox Parameters

| 顺序 | 参数 | 中文数据类型 | 要求 | 默认值 |
|---:|---|---|---|---|
| 0 | 输入时序文件 | 文件（多值） | 必选，CSV/Excel，多文件用分号分隔 | 无 |
| 1 | 时间字段 | 字符串 | 必选，验证器读取输入文件字段并生成下拉框 | 输入文件首字段 |
| 2 | 数值字段 | 字符串 | 必选，验证器读取输入文件字段并生成下拉框 | 输入文件第二字段 |
| 3 | 缺失值标记 | 双精度/字符串 | 可选，用于识别缺失值；不是下拉框 | -99999 |
| 4 | 按时间排序 | 布尔值 | 可选，复选框 | true |
| 5 | 重复时间处理 | 字符串 | 可选，下拉：error/mean/first/last | error |
| 6 | 输出 HTML 报告 | 文件 | 可选，验证器根据输入文件自动填充 | 自动生成 |
| 7 | 输出文件夹 | 文件夹 | 必选，验证器根据输入文件自动填充 | 输入文件所在文件夹 |
| 8 | 打开 HTML 报告 | 布尔值 | 可选，复选框 | true |
| 9 | 滞后阶数 | 长整型 | 必选，用于生成 lag_1 到 lag_n 历史特征；不是下拉框 | 3 |
| 10 | 训练测试比例 | 字符串 | 可选，例如 8:2 或 0.2；不是下拉框 | 8:2 |
| 11 | 交叉验证折数 | 长整型 | 可选，TimeSeriesSplit 使用；不是下拉框 | 3 |
| 12 | 插补最小值 | 双精度 | 可选，插补结果下限；不是下拉框 | 0 |
| 13 | 插补最大值 | 双精度 | 可选，插补结果上限；留空表示不限制 | 空 |
| 14 | 加入趋势特征 | 布尔值 | 可选，复选框 | false |
| 15 | 加入季节特征 | 布尔值 | 可选，复选框；按时间字段提取月份 sin/cos | false |
| 16 | 随机种子 | 长整型 | 可选，用于结果可复现；不是下拉框 | 42 |
| 17 | 学习率 | 双精度 | 可选，learning_rate；单值；不是下拉框 | 0.1 |
| 18 | 树数量 | 长整型 | 可选，n_estimators；单值；不是下拉框 | 100 |
| 19 | 最大深度 | 长整型 | 可选，单值；不是下拉框 | 3 |
| 20 | 叶节点最小样本数 | 长整型 | 可选，min_samples_leaf；单值；不是下拉框 | 1 |
| 21 | 子采样比例 | 双精度 | 可选，0 到 1；单值；不是下拉框 | 1.0 |
| 22 | 损失函数 | 字符串 | 可选，下拉：squared_error/absolute_error/huber/quantile | squared_error |
| 23 | Python3 路径 | 文件 | 可选，python.exe；留空使用默认环境或 ARCWATER_PY3 | 空 |
